1. HTML Sectioning

HTML sectioning organizes a webpage into different meaningful parts. Examples include header, main, section, article, and footer.

2. 3 Types of CSS

Inline CSS

CSS written directly inside an HTML element using the style attribute.

Internal CSS

CSS written inside the <style> tag of an HTML file.

External CSS

CSS written in a separate CSS file and connected to HTML using the <link> tag.

3. CSS Selectors

CSS selectors are used to choose HTML elements that will be styled.

  • Element Selector – selects elements such as body, p, h1, and h2.
  • Class Selector – uses a class such as .section.
  • ID Selector – uses an ID such as #welcome.

4. CSS Border

CSS borders create an outline around an HTML element. Borders can have different colors, widths, and styles.

This webpage uses solid, dashed, double, and dotted borders as part of its design.

5. CSS Background

CSS backgrounds can be used to add colors, gradients, or images behind HTML elements.

This homepage uses different shades of pink and gradients to create a soft and creative appearance.

6. CSS Box Model

The CSS Box Model consists of four main parts:

  • Content – the actual information
  • Padding – space around the content
  • Border – outline around the element
  • Margin – space outside the border
